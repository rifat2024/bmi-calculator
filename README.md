# BMI Calculator

A responsive BMI Calculator built with **HTML, Tailwind CSS and JavaScript**.

## Features

- Calculate BMI using weight and height
- Height input using feet and inches
- BMI category detection
- Input validation
- 2-second loading animation
- Animated loading indicator
- Responsive design
- Clean and simple UI

## BMI Categories

| BMI | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal |
| 25 – 29.9 | Overweight |
| 30 or above | Obese |

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript

## How It Works

The calculator converts the user's height from feet and inches into meters and then calculates BMI using:

**BMI = Weight (kg) / Height² (m)**
